### Граничні випадки

- **Зарплата:** перевернута вилка `$6000-5000`, «до» / «від», погодинна ставка, «за домовленістю», відсутнє поле, число з пробілом `45 000`, валюта (USD, EUR, UAH); без валюти — долар для Djinni, гривня для Work.ua, але `$` у рядку важливіший.
- **Дата:** «щойно», «сьогодні», «вчора», «1 день», «3 дні», «5 годин», «10 хв» тому; `08.10.2026` не плутається з 10 серпня; ISO 8601; дата з майбутнього стає поточною; невідомий чи відсутній формат.
- **Посилання:** фішингові домени `djinni-careers.example.net`, `djinni.co.evil.example`, `fakedjinni.co`; `http://`; не URL; відсутнє посилання; посилання на Djinni у вакансії з Work.ua. Піддомени `jobs.djinni.co` і `www.work.ua` приймаються, трекінгові параметри відрізаються. Джерело `Unknown` чи ще не підтримане `RobotaUa` відхиляється.
- **Текст:** `<script>` і `<style>` вирізаються разом із вмістом, HTML-сутності декодуються, абзаци й пункти списку стають рядками.
- **Довжина:** назва з 1 символу відхиляється, з 2 (QA, PM) — приймається; id довше 100 і назва довше 200 символів обрізаються до розміру колонки; рівно 200 — без змін; порожні поля стають `null`, «Не вказано» чи «Інше».
- **Навички:** лише з поля сайту — без нього список порожній, навіть якщо в описі є «C# та PostgreSQL»; поле Djinni є, його немає (і тоді не береться «Англійська» з наступного блоку) чи частина схована за «+ ще 3» (кнопка й скрипт у навички не потрапляють); мітки Work.ua є чи їх немає; `&amp;` у полі; кирилиця й `C/C++` зберігаються в JSON без `\u`-екранування.
- **Сторінка Djinni:** зарплата діапазоном, «до» / «від», одним числом, рядком, погодинна, у незнайомій валюті, без суми; досвід 0, 6, 18 місяців, 1, 3, 5, 11, 21 рік (відмінки «рік / роки / років») і текстом; віддалено, офіс з містами, місто без країни, кілька офісів; невідомий тип зайнятості; київський час улітку (+03:00) і взимку (+02:00), дата з готовим зсувом; `List<T>` та `&` в описі; JSON-LD організації чи хлібних крихт; капча замість сторінки; зламаний JSON-LD.
- **Сторінка Work.ua:** вилка з `&#8239;` і `&thinsp;`, мітка «Вища за середню» без суми, мітка «перевірена компанія», місто з посиланням «1,0 км від центру», «Дистанційно»; дата «9 жовтня», «1 січня», «31 грудня», «Травня» з великої, невідомий місяць, підказка без дати; порожнє посилання (назва з підказки); посилання на компанію замість вакансії, схожий клас `job-linked`, картка без посилання; графік із `·` в окремому тезі; сторінка без навичок, досвіду й категорії.
- **robots.txt:** `Disallow: /*/?*sort=`, `/jobs-*-/`, `/*.php`, `Allow: /jobseeker/my/resumes/$` проти `Disallow: /jobseeker/my/`, `Allow: /*/?*student=` проти `Disallow: /*/?*sort=`; порожній `Disallow`; група іншого бота; кілька `User-agent` поспіль; регістр назв полів; коментарі; `\r\n`.
- **Обхід сайту:** вакансія, що під час обходу з'їхала на наступну сторінку, не дублюється; обхід зупиняється на повторі першої сторінки (Djinni), на порожній сторінці (Work.ua) чи на ліміті сторінок; код 503 чи тайм-аут на другій сторінці не губить першу; сторінка вакансії відкривається один раз, поки вакансія в списку, а зникла вакансія забувається; обірваний обхід нічого не забуває; код 429 на сторінці вакансії не губить вакансію, а решта сторінок вакансій у цьому зборі не відкривається; посилання не на сам сайт не відкривається; `robots.txt` із забороною чи з кодом 500 — сайт пропускається, 404 — дозволено все, заборонена сторінка вакансії не відкривається.
- **Пауза після відмови:** 403, 429 і 503 вмикають паузу, 500 і 404 — ні; пауза 1 год → 2 год (запуски за розкладом посеред паузи не роблять запитів), успіх скидає її знову до 1 год; `Retry-After: 3 год` довший за власну паузу — чекаємо 3 год; обхід, обірваний тайм-аутом, не вмикає паузи.
- **Налаштування:** значення з `appsettings.json` і самі межі приймаються; інтервал 10 с, пауза 0,1 с, 11 сторінок чи −1 сторінка — ні.
- **Файли:** зламаний JSON, `null`, чужий `source`, дамп без `jobs`, відсутня папка; зламаний файл не зупиняє обробку інших.
- **Збереження:** повторний імпорт оновлює запис, а `Id`, дата публікації й дата першої появи не змінюються; той самий id з іншого сайту — окрема вакансія; дубль у межах одного дампу; порожній пакет.

Тест на `fakedjinni.co` і перевірка незмінної дати публікації з'явилися після практики «Зламай, потім відлагодь» (Lab 06): внесені туди помилки попередній набір тестів не помітив.

У звіті 99,6 % рядків (816 з 819), 95,7 % гілок і 100 % методів. `BulkUpsertAsync` у звіт не входить, бо цей метод лежить у класі репозиторію Дениса разом з чужими методами; окремо він покритий повністю (19 з 19 рядків).

Непокритими лишилися 3 рядки, і до кожного тест не дістанеться:

- вихід із циклу в `JobParserService.ExecuteAsync`, коли `PeriodicTimer.WaitForNextTickAsync` повертає `false`. Так буває, лише якщо таймер знищити під час очікування, а наш код цього не робить. Сервіс зупиняється через скасування, і цей шлях покриває тест `Parser_RereadsDirectoryOnSchedule`;
- запасний `TimeZoneInfo.Utc` у `DjinniParser.FindKyivTime` — лише для системи без бази часових поясів;
- гілка `_ => throw` у `SubtractTimeAgo`: regex `TimeAgo` пропускає лише відомі одиниці, а виняток стоїть на випадок, якщо regex розширять, а `switch` забудуть.

## Як запустити

Тести (прапорці `-p:...` потрібні лише на Windows без MAUI-воркладів):

```bash
dotnet test tests/waterfall.Ingestion.Tests/waterfall.Ingestion.Tests.csproj -p:TargetFrameworks=net10.0 -p:TargetFramework=net10.0
```

Перегенерувати звіт покриття. Спершу зібрати дані:

```bash
dotnet test tests/waterfall.Ingestion.Tests/waterfall.Ingestion.Tests.csproj -p:TargetFrameworks=net10.0 -p:TargetFramework=net10.0 --collect "XPlat Code Coverage" --results-directory TestResults/ingestion
```

Потім побудувати HTML лише для класів модуля:

```bash
dotnet tool restore && dotnet tool run reportgenerator "-reports:TestResults/ingestion/**/coverage.cobertura.xml" "-targetdir:tests/waterfall.Ingestion.Tests/coverage-report" "-reporttypes:Html;TextSummary" "-classfilters:+Waterfall.Api.Workers.*;+Waterfall.Services.VacancyIngestionService;+Waterfall.Services.Interfaces.RawVacancy;+Waterfall.Services.Interfaces.IngestionResult"
```

Каталог `TestResults/` у `.gitignore`. Після генерації абсолютні шляхи до файлів у HTML варто замінити на відносні.
