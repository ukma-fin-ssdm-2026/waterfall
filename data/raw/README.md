# Сирі дані для фонового збору вакансій

Фоновий воркер `VacancyIngestionWorker` періодично читає всі файли `*.json` з цього каталогу, розбирає їх, нормалізує записи й зберігає вакансії в БД. Повторний запуск не дублює вакансії: запис оновлюється за парою «джерело + id на сайті».

Зараз підтримується одне джерело — дамп Djinni. Це перший етап збору даних, узгоджений з командою: парсинг HTML сайтів додасться пізніше як ще одна реалізація `IRawVacancySource` без змін у нормалізації та збереженні.

## Формат дампу Djinni

```json
{
  "source": "djinni",
  "exportedAt": "2026-10-12T07:30:00Z",
  "jobs": [
    {
      "id": "720001",
      "url": "https://djinni.co/jobs/720001-senior-net-developer/",
      "title": "Senior .NET Developer",
      "company": "Kvitka Software",
      "salary": "$3500-4500",
      "location": "Kyiv, Remote",
      "posted": "2 дні тому",
      "experience": "5 років досвіду",
      "employment": "Full Remote · Повна зайнятість",
      "category": ".NET",
      "descriptionHtml": "<p>Опис вакансії з HTML-тегами</p>",
      "tags": "C#, .NET; PostgreSQL | Docker"
    }
  ]
}
```

| Поле | Обов'язкове | Як нормалізується |
| --- | --- | --- |
| `id` | так (або число на початку останнього сегмента `url`) | рядок або число; разом із джерелом утворює ключ для оновлення |
| `url` | так | лише `djinni.co` і його піддомени; параметри запиту й фрагмент відкидаються; посилання з логіном чи нестандартним портом відхиляється |
| `title` | так | пробіли стискаються; щонайменше 3 символи |
| `descriptionHtml` | так | HTML перетворюється на текст, вміст `<script>` і `<style>` відкидається |
| `company` | ні | за відсутності — «Не вказано» |
| `salary` | ні | `$3500-4500`, `від $2000`, `до $2500`, `€2.5k–3.5k`, `1500 USD`; погодинні ставки не перераховуються; валюта за замовчуванням для Djinni — USD |
| `location` | ні | `Kyiv, Remote` → «Київ (віддалено)», `Remote` → «Віддалено» |
| `posted` | ні | `сьогодні`, `вчора`, `2 дні тому`, `08.10.2026`, `8 жовтня 2026`, ISO 8601; без дати — момент збору |
| `experience` | ні | `5 років досвіду` → «5+ років», `без досвіду` → «Без досвіду» |
| `employment` | ні | зберігається як графік роботи |
| `category` | ні | за відсутності визначається за назвою посади й навичками |
| `tags` | ні | рядок через `,` `;` `\|` або масив рядків; дублікати й синоніми (`k8s`, `ts`) зводяться до однієї назви |

Назви полів нечутливі до регістру; невідомі поля ігноруються. Файл, більший за `Ingestion:MaxFileSizeBytes` (10 МБ), або документ з понад 5000 записами не обробляється.

## Демонстраційний дамп

`djinni-sample.json` містить **синтетичні** дані: компанії й ідентифікатори вигадані, посилання на сайт не ведуть на справжні вакансії. Три записи в ньому навмисно невалідні й відкидаються з поясненням у журналі:

- запис без назви посади;
- запис з посиланням на сторонній домен — приклад фішингової вакансії з моделі загроз (THR-03);
- рядок замість JSON-об'єкта.

## Налаштування

Секція `Ingestion` в `src/api/appsettings.json`:

| Параметр | За замовчуванням | Призначення |
| --- | --- | --- |
| `Enabled` | `true` | вмикає фоновий збір |
| `RawDataDirectory` | `../../data/raw` | каталог з дампами, відносно `src/api` |
| `Interval` | `00:30:00` | пауза між циклами збору (не менше хвилини) |
| `InitialDelay` | `00:00:10` | затримка першого циклу після старту застосунку |
| `MaxFileSizeBytes` | `10485760` | максимальний розмір файлу дампу |
