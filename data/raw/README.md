# Сирі дані для фонового збору вакансій

`JobParserService` (src/api/Workers) раз на 30 хвилин читає всі файли `*.json` з цього каталогу й передає вакансії в `VacancyIngestionService`, який чистить їх і зберігає в БД. Повторний запуск не дублює вакансії: запис оновлюється за парою «джерело + id на сайті».

Поки що підтримується один сайт — Djinni (домовленість команди). Цей файл — контракт для скрейпера: він має складати дамп саме в такому форматі.

## Формат дампу Djinni

```json
{
  "source": "djinni",
  "jobs": [
    {
      "id": "720001",
      "url": "https://djinni.co/jobs/720001-senior-net-developer/",
      "title": "Senior .NET Developer",
      "company": "Kvitka Software",
      "salary": "$3500-4500",
      "location": "Kyiv, Remote",
      "posted": "2 дні тому",
      "experience": "5 років досвіду",
      "employment": "Full Remote",
      "category": ".NET",
      "descriptionHtml": "<p>Опис вакансії з HTML-тегами</p>",
      "tags": "C#, .NET, PostgreSQL"
    }
  ]
}
```

| Поле | Обов'язкове | Що з ним відбувається |
| --- | --- | --- |
| `id` | так | рядок; разом із джерелом — ключ для оновлення |
| `url` | так | лише `https://djinni.co/...`; параметри після `?` відкидаються |
| `title` | так | зайві пробіли прибираються; щонайменше 3 символи |
| `descriptionHtml` | так | HTML → текст, `<script>` і `<style>` видаляються |
| `salary` | ні | `$3500-4500`, `від $2000`, `до $2500`, `€2500–3500`, `1500 USD`; погодинна ставка й «за домовленістю» → без зарплати; валюта за замовчуванням — USD |
| `posted` | ні | `сьогодні`, `вчора`, `3 дні тому`, `5 годин тому`, `10 хв. тому`, `08.10.2026`, ISO 8601; інше — дата збору |
| `company`, `location`, `category` | ні | порожнє → «Не вказано» / «Інше» |
| `experience`, `employment` | ні | зберігаються як є |
| `tags` | ні | рядок через `,` `;` або `\|`; дублікати прибираються |

## Демонстраційний дамп

`djinni-sample.json` — **вигадані** дані: компанії й ідентифікатори не справжні. З 12 записів 10 зберігаються, а 2 навмисно відкидаються з поясненням у журналі: запис без назви посади і запис із посиланням на сторонній домен (фішингова вакансія з моделі загроз, THR-03).

Коли з'являться справжні дампи, демонстраційний файл треба прибрати, щоб вигадані вакансії не змішувалися з реальними.

## Налаштування

Секція `Ingestion` в `src/api/appsettings.json`:

| Параметр | Значення | Призначення |
| --- | --- | --- |
| `Enabled` | `true` | вмикає фоновий збір |
| `RawDataDirectory` | `../../data/raw` | каталог з дампами, відносно `src/api` |
| `Interval` | `00:30:00` | як часто перечитувати каталог |
