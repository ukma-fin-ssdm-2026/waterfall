# ADR-001: Модульний моноліт замість мікросервісів

- Статус: прийнято
- Дата: 2026-09-25
- Автор рішення: Денис

## Контекст

Команда з 4 осіб, єдиний дедлайн Lab 3, навантаження каталогу помірне (PERF-001: 100 одночасних користувачів). Мікросервіси дають незалежне масштабування ціною мережевої складності, окремих деплоїв і міжсервісних контрактів.

## Рішення

Clean / Layered Architecture в одному процесі: .NET MAUI клієнт → Core Services → Repository Layer. Збір вакансій — `BackgroundService` всередині процесу (§3.4.1), без окремих воркерів.

## Наслідки

+ Один деплой, DI-виклики замість мережі, REL-003 ізоляція модульними межами.
− Вертикальне масштабування; винесення Parser в окремий сервіс — зарезервовано, межа вже проведена (§3.4).
