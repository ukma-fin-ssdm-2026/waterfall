# ADR-003: Cache-Aside In-Memory кеш каталогу

- Статус: прийнято
- Дата: 2026-09-27
- Автор рішення: Дмитро

## Контекст

PERF-001: сторінка 20 вакансій <1 с p95 при 10k записів. Прямі запити в DB на кожну фільтрацію не вкладаються.

## Рішення

Читання `Storage → Cache → DB` з TTL та інвалідацією при надходженні нових вакансій (§3.3.2, §3.4.2). Агреговані аналітичні звіти кешуються, персональні рекомендації — ні (FR-006, on-demand ранжування).

## Наслідки

+ Каталог p95 <1 с; REL-001: за недоступності джерела — stale-cache ≤12 год з міткою часу.
− Волатильність при рестарті (прийнято: прогрів з DB; запис збережень синхронний, REL-002).
