### Functional Requirements
| ID         | Назва функції                     | Опис вимоги                                                                                                                                                                                                                                       |
| ---------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FR-001** | Пошук та кешування даних вакансій | Система повинна автоматично збирати дані про вакансії із різних сайтів, зберігати в єдиному стандартизованому форматі, який обов'язково включає: назву посади, назву компанії, опис, ЗП, формат роботи та URL.                                    |
| **FR-002** | Обробка запитів ШІ-асистентом     | Система повинна надавати текстовий чат, через який шукач роботи може надіслати запит, а система повинна передати цей запит з контекстом з додатку до API обраної LLM та повернути відповідь у вигляді тексту або списку відфільтрованих вакансій. |
| **FR-003** | Ринкова аналітика                 | Система повинна розраховувати та відображати аналітику для Аналітика/Роботодавця: середнє значення заробітної плати, порівняння попиту на стек технологій та динаміку публікацій нових вакансій за заданими фільтрами.                            |
| **FR-004** | Фільтрація та пошук               | Система повинна надавати користувачу можливість шукати вакансії за ключовими словами та застосовувати фільтрацію за: категорією, рівнем заробітної плати, форматом роботи та стеком технологій.                                                   |
| **FR-005** | Збереження вакансій               | Система повинна дозволяти Шукачу роботи зберігати обрані вакансії до власного списку, "лайкати" та переглядати, видаляти або переходити за посиланнями збережених вакансій у спеціальному розділі профілю.                                        |
| **FR-006** | Індивідуальні рекомендації        | Система повинна аналізувати збережені вакансії лайки та історію переглядів Шукача роботи для автоматичного коригування видачі, піднімаючи релевантні пропозиції вище у списку вакансій.                                                           |
| **FR-007** | Особиста статистика користувача   | Система повинна збирати та відображати Шукачу роботи в його профілі статистику активності: кількість збережених вакансій, історію пошукових запитів та частоту переглянутих категорій/технологій.                                                 |
| **FR-008** | Розділення між ролями             | Система повинна підтримувати базове розділення між ролями "Шукач роботи" (доступ до рекомендацій, лайків) та "Роботодавець / Аналітик" (доступ до розширеної аналітики).                                                                          |
