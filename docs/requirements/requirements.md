### Functional Requirements
| ID         | Назва функції                     | Опис вимоги                                                                                                                                                                                                                                                      |
| ---------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FR-001** | Пошук та кешування даних вакансій | Система повинна автоматично парсити дані про вакансії із різних сайтів, зберігати у базі даних та кешувати для швидкого доступу в єдиному стандартизованому форматі, який обов'язково включає: назву посади, назву компанії, опис, ЗП, формат роботи та URL-посилання на оригінальне джерело. |
| **FR-002** | Обробка запитів ШІ-асистентом     | Система повинна надавати текстовий чат, через який шукач роботи може надіслати запит, а система повинна передати цей запит з контекстом з додатку до API обраної LLM та повернути відповідь у вигляді тексту або списку відфільтрованих вакансій.    |
| **FR-003** | Аналітика                         | Система повинна розраховувати та відображати аналітику/роботодавцю середнє значення заробітної плати, попиту і вимог до шукача роботи для заданих фільтрів на основі даних про вакансії.                                                                         |
